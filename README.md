# 💣 Ultimate Bomb Factory

## An 2D auto-runner game made for the game jam Alchemy Jam #7

- This is an auto-runner game focused on escaping the factory before the bomb explodes
- You're a samurai sent to steal a secret prototype from the world's most dangerous bomb factory, but you were captured
- Now, you must escape to save your life, defeating the robots and avoiding the obstacles!

**_Game controls:_**
| Action | Keyboard | Controller |
| ------ | -------- | ---------- |
| Move character | WASD/Keys | Analog |
| Move menu options | WASD/Keys | D-pad |
| Jump | J / Z | A or Cross |
| Attack | K / X | X or Square |
| Pause | P / Alt / Esc | Start |
| Confirm | Spacebar / Enter | Start / A or Cross |
